# Changelog

All notable changes to FWAudit are documented here.

## Current Version — Initial Release

### Added
- CSV firewall rule parsing and validation.
- Detection of any-to-any allow rules.
- Detection of unrestricted SSH and RDP access.
- Potential shadowed rule detection.
- Detection of deny rules with logging disabled.
- Command-line interface for firewall audits.
- Tkinter graphical user interface.
- Dashboard with audit statistics and risk summary.
- Audit report generation and report history.
- Report viewing and deletion.
- Six test scenarios for verification.
- Project documentation and usage instructions.
